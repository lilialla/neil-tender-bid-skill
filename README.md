# 招投标 Skill 工具

面向律师团队的私有 Codex Skill。目标是减少采购要求遗漏、材料错配和重复返工，并保留人的业务决定权。

## 当前状态

仓库已初始化；Skill 尚未实现、安装或完成样本验收。

## 实施路线

1. Phase 0：完整读取采购来源，形成来源覆盖记录和九列要求总账。
2. Phase 1：完成两个关联章节的要求映射、独立上下文执行与局部返工验证。
3. Phase 2：完成单项目需要的文件集、装配及分阶段检查。

本仓库只保存通用源码、说明和合成测试数据；真实采购文件、响应文件、证照、社保、报价资料和会议转录保留在独立的业务目录。
